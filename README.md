# MV Prompt Director

v2.1 · 根据主体图片和可选风格参考图创作音乐 MV，并调用当前可用的视频生成工具交付视频。

默认目标：**Seedance 2.5 · 30 秒 · 16:9 · 1080p · 有声**。用户明确指定的模型和规格优先；实际支持范围由宿主视频工具决定。

## 功能

- 有风格参考图时，按参考图编排服装、场景、灯光与音乐。
- 只有主体图时，从七套预设中按文字匹配；无偏好时等概率随机选取一套。
- 编排分镜、人物表演、原创歌词、声部分工和音画时间，检查人物与场景连续性。
- 支持多人合照、保留原服装、单场景、局部修订和仅提示词模式。
- 完成提示词后调用当前视频工具，获取真实生成结果并交付成片或视频链接。

## 安装

1. 下载本仓库，并保留完整目录结构。
2. 使用宿主 Agent 提供的 Skill 导入方式，加载包含 `SKILL.md` 的整个文件夹。
3. 按宿主提示刷新或新开会话，确认 Skill 可用。

直接生成视频需要宿主能读取 Skill 文件、查看参考图片并调用视频生成工具。没有视频工具时，可使用仅提示词模式。具体安装位置和调用语法以宿主说明为准。

## 使用示例

上传主体图后，发送：

> 使用 mv-prompt-director，以照片中的人物为主体，生成梦核女团风音乐 MV。保留原服装，其他创作设定请合理补全。

有风格参考图时，标明分工：

> 图1是主体；图2参考穿搭；图3参考场景。生成30秒、16:9横幅音乐 MV。

只需要提示词时，发送：

> 根据这张主体图创作音乐 MV，只要完整提示词，先不要生成视频。

## 生成流程

查看图片 → 判断素材用途 → 按图创作或选择预设 → 编排并检查提示词 → 检查当前视频工具能力 → 提交一次生成 → 获取并交付结果。

素材引用、授权、参数和任务查询方式遵循实际工具说明与返回结果。Skill 不要求固定工具名、外部接口或特定素材编号。工具不能满足要求时，保留方案并说明缺项。
