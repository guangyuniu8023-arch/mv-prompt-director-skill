# Subject-only Presets

仅在所有上传图片都是主体图、没有风格参考图时读取。当前共七套：P1–P4 的视觉定义来自《SKILL 使用说明和附赠图片提示词模板.pdf》第 5–8 页，编号与 PDF 的 IMAGE PROMPT 01–04 一致；P5–P7 是根据用户提供的三支视频提炼的新增模板，定义见 [video-inspired-presets.md](video-inspired-presets.md)。每次只选一套，不把不同模板拼成多个场景。

PDF 提供的是四套 Hip-hop 图片提示词。下文保留原始提示词，并补充音乐、主动表演与 30 秒编排用于 MV 创作，再按核心 Skill 的生成或仅提示词模式交付；这些动态补充不是 PDF 原文。原始图片提示词中的 4:3 仅记录 PDF 原文，当前 MV 交付默认推荐 16:9 横幅。运行时使用本文件，不要求用户先生成风格图或另行提供 PDF。

## 文字优先、随机兜底的选择规则

只根据用户文字选择，不根据主体照片的外貌、性别、年龄、服装或气质选择。按以下顺序处理：

1. 用户明确指定模板名称或某套独有场景时，直接采用对应套。
2. 否则，按下表匹配明确的音乐子类型；没有对应子类型时，再匹配明确氛围。
3. 同时命中多套时，采用用户最后明确指定或重点强调的一套；仍不能唯一匹配时，在命中的候选集合中等概率随机抽取一套。
4. 只有“Hip-hop、嘻哈、说唱、夜晚、酷”等泛化描述，或没有音乐与氛围偏好时，从 P1–P7 中等概率随机抽取一套。用户指定的音乐仍优先于选中模板的默认音乐。没有固定默认模板，不追问用户。

在当前 Skill 目录运行 `python3 scripts/select_preset.py`，使用输出的预设编号；七套各占 1/7（约 14.29%）。候选集合受文字限制时，传入候选编号，例如 `python3 scripts/select_preset.py --candidates P2 P4`；仅从三套新增模板随机时使用 `--candidates P5 P6 P7`。用户明确排除的预设不能进入候选集合；用户明确要求随机时遵守其指定的候选范围。没有执行环境时，调用所用 Agent 可用的随机工具。实际执行随机选择，使用工具返回的结果。

候选集合只有一套时直接采用该套；为空时说明场景约束冲突，仅就可用场景简短追问，不调用空候选、不选被排除项，也不要求补风格图。没有随机脚本或随机工具可用时如实说明无法执行抽取，不声称已完成随机选择。

每次新创作只抽取一次，选定后在整支 MV 和后续修订中保持一致。只有用户明确要求重新随机时才重抽；明确指定换另一套时直接采用指定套，不运行随机。用户要求换不同的一套时排除当前套，普通重新随机允许再次抽中当前套。独立创作允许重复抽中同一套，不用轮换代替随机，不刻意避开上一套，也不使用固定随机种子。

“复古”同时匹配 P1、P6；只有该词时在两套中等概率随机。“Old fashion／Old school”明确采用 P6。“K-pop／韩国女团”在未指定场景时匹配 P5；“韩国女团＋工业夜行”直接采用 P4 并保留 K-pop 音乐。“电气朋克”匹配 P7，而只有“工业／暗黑”按 P4；两者不互相替代。

用户明确指定的具体内容优先于预设，例如歌词语言、保留服装、画幅或某个场景。只在所选预设内部调整，不借用其他预设的视觉、场景、服装、灯光或表演元素。

下方音乐、BPM、服装和表演描述是默认补全，用户覆盖后须重新编排音画。

## 人物适配通则

- 多张同一人的主体图共同稳定身份；多人主体分别建立角色、服装和声部映射，单人女团风不额外添加成员。不能把多张本人照片误判为风格图。
- 将原文中的人物占位符替换为上传主体，保留面部、发型和明确身份特征，不复制 PDF 或视频中人物的脸、年龄或性别。“年轻音乐人”、四人女团、爷奶组合都不是改变用户主体的要求。
- 默认采用所选模板服装，用户明确要求保留原服装时锁定可见的颜色、剪裁、材质、印花与明确饰件，未展示部分仅作自然延续。按服装活动空间安排动作，不把保留原服装当作新增风格图。
- 只有头肩照时增加近景与半身表演，减少复杂步伐、跳跃和大幅转体；全身画面采用保守姿态。不要因此索要补图、推断专业表演能力或更换模板。
- 七套预设的 MV 默认画幅统一为 16:9 横幅；用户明确画幅优先。按目标画幅重新安排人物与场景空间，保留脸部、关键动作和道具关系，避免拉伸主体或裁掉关键内容。素材构图影响画面内的取景，不影响预设选择。
- 只使用所选模板的场景、车辆、光色与关键视觉元素；服装和音乐以用户明确要求优先。P4 的三只犬属于该套定义，其他套不加入犬；P3 的悬浮与烟火不进入其他套。
- 用户指定第二主唱时，不默认降为同伴。握持道具时先确定持握者和占用手，再安排自由手编舞，连接关系贯穿全片。
- 原始图片构图是拍摄母题，不是 30 秒必须保持的定帧。围绕同一套场景发展远中近、主动表演与动作细节。
- P5–P7 中的星形、白布、机械装置等是默认视觉载体，可按用户要求替换或省略；锁定的是实际选用后的数量、连接和世界状态。视频中的额外人物、品牌、字幕、吸烟或宗教身份不自动带入新创作。

## P1 午夜红车 · After hours.

来源：PDF 第 5 页，HIP HOP / IMAGE PROMPT 01。

**原始图片提示词**

```text
4:3 横幅 Hip Hop 音乐录影带定妆照。【年轻音乐人】从【红色复古轿车】旁俯身靠近镜头，佩戴窄框墨镜，穿【白色上衣和毛绒外套】，一只手伸向广角镜头，神情自信。高机位微俯拍，24mm 广角，手掌在前景。直接闪光灯照亮皮肤与衣料，背景深黑，红色车漆成为高饱和点缀。35mm 胶片颗粒，轻微曝光不均，真实抓拍，服装质感清楚。不要文字、水印、畸形手指。
```

原文可替换项：人物、车辆、服装；同一人物多次生成时固定人物参考图。主体图路径默认使用红色复古轿车、窄框墨镜、白色上衣与毛绒外套，保留高机位广角、前景手掌、直接闪光、深黑背景与红色车漆。

**MV 动态补充**

- 音乐：默认 96 BPM、4/4 Hip-hop，干脆鼓点、厚实低频与简短旋律采样；原创短句说唱，后段增强声部，最后留出收势。
- 表演：车旁俯身接近镜头、伸手后收回、肩颈踩拍、扶车门转身、稳定近景演唱。墨镜与外套保持连续，手掌不持续遮脸。
- 摄影与剪辑：先建立红车位置，再用高机位 24mm 广角复现母题；穿插车漆、衣料与手部细节和稳定中近景。用鼓点、伸手与车门遮挡衔接，直接闪光只在明确切点使用。
- 30 秒推进：0–3 秒红车与手部钩子；3–11 秒车旁主歌；11–19 秒同车周围的中近景与细节；19–27 秒俯身伸手的表演高潮；27–30 秒收手、停稳并完成最后一句与落版。
- 连续性：同一辆车、同一主体、同一套服装；不加入红蓝车厢、烟火悬浮或犬群。

## P2 红蓝车厢 · Backseat voices.

来源：PDF 第 6 页，HIP HOP / IMAGE PROMPT 02；页面标注 TRAP / GRIME / NIGHT。

**原始图片提示词**

```text
4:3 横幅 Hip Hop 音乐录影带剧照。夜晚的【黑色轿车】内，【主唱和一名同伴】穿【白色针织帽与蓝色格纹外套】。主唱靠近车窗，手臂搭在车门，直视镜头；同伴在后排，保持独立面孔。车外低机位近窗口拍摄，车框形成自然画框。红色顶灯覆盖皮肤与金属，窗外冷蓝光从下方反射。直接闪光、深黑阴影、真实皮肤与高感胶片颗粒。临时停车说唱的纪实氛围。不要人物融合、多余手臂、文字或水印。
```

原文可替换项：车辆、人物、服装；明确每个人的位置，保留红蓝双色光。主体图路径默认保留黑色轿车、白色针织帽、蓝色格纹外套和车窗画框。有明确第二角色时安排同伴在后排；只有一名主体时省略同伴，不复制 PDF 的其他人物，也不将同一主体复制成两个人。

**MV 动态补充**

- 音乐：默认 140 BPM、4/4 Trap，半拍体感，808 低频、高帽与稀疏暗色音色；用户指定 Grime 时使用 Grime 节奏。原创短句说唱，给口型与停顿留空间。
- 表演：主唱靠近车窗、手臂搭在车门、转头直视镜头、手部打拍与上半身律动；有同伴时只安排独立的后排反应。
- 摄影与剪辑：车外低机位沿窗口短距离横移，车框形成画框；切主唱近景、车门手部与车厢纵深。红色顶灯和窗外冷蓝反光方向固定，用车柱遮挡、视线与鼓点连接。
- 30 秒推进：0–3 秒车框与双色光钩子；3–11 秒主唱靠窗演唱；11–19 秒近景与手部细节，或明确同伴的后排反应；19–27 秒节奏增强与靠窗表演高潮；27–30 秒视线收稳、末句与落版。
- 连续性：轿车始终临时停靠，不在行驶中让人物探出身体；角色位置固定；不加入红色复古车、烟火或犬群。

## P3 烟火巷道 · Into the air.

来源：PDF 第 7 页，HIP HOP / IMAGE PROMPT 03。

**原始图片提示词**

```text
4:3 横幅超现实 Hip Hop MV 高潮剧照。狭窄的混凝土巷道中，【穿长外套的音乐人】被节拍冲击托起，身体悬浮半空，四肢自然受力，轮廓明确。地面附近的24mm超广角向上拍摄，墙面形成透视引导线。身后绽放巨大白金色烟火，火花向四周展开，橙红烟雾充满空间。人物呈深色剪影，保留衣服边缘光。高速快门凝固火花，人物轻微运动拖影，胶片颗粒与真实烟雾层次。不要舞台、观众、超级英雄服装、畸形或水印。
```

原文可替换项：人物、服装颜色；保留完整轮廓及烟火与人物的前后层次。主体图路径默认用深色长外套、混凝土巷道、地面低机位 24mm 超广角、白金色烟火、橙红烟雾与衣服边缘光，不将场景改成舞台。

**MV 动态补充**

- 音乐：默认 96 BPM、4/4 电影感 Hip-hop，沉重鼓组与低频，前段克制铺垫，高潮加入更宽的音色与和声；原创短句说唱或旋律说唱，托起动作与重拍一致。
- 表演：巷道中缓步演唱、站定蓄力、被节拍托起后四肢自然展开、悬浮时以头肩和手势承接声音。减少复杂翻转，保留完整人体轮廓；先用可辨认面部的镜头建立主体，再进入剪影高潮。
- 摄影与剪辑：近景演唱与低机位空间建立交替，高潮从地面附近向上拍摄，墙面透视指向主体；稳定悬浮构图承接烟火展开，不连续绕整圈。
- 30 秒推进：0–3 秒巷道与衣料钩子；3–11 秒走入空间并演唱；11–19 秒站定、低机位与声音蓄力；19–27 秒托起、白金烟火展开与悬浮高潮；27–30 秒保持明确悬浮状态、完成末句与落版。
- 连续性：烟火位于人物后方，前后层次不倒置；人物可有轻微拖影，不能全程冻结演唱动作。只有明确的短时变速镜头才凝固火花；返回镜头维持悬浮与烟雾状态。不加入车辆、犬群、观众或超级英雄服装。

## P4 工业夜行 · Night walkers.

来源：PDF 第 8 页，HIP HOP / IMAGE PROMPT 04；页面标注 INDUSTRIAL / DARK / STREET。

**原始图片提示词**

```text
4:3 横幅暗黑 Hip Hop 音乐录影带剧照。夜晚空旷工业场地，【音乐人】背对镜头前行，穿黑色天鹅绒夹克和宽松长裤，背面使用【自有文字或 Logo】。三只【黑色杜宾犬】向左侧奔跑，人与犬之间的红色牵引线穿过烟雾，形成清晰视觉路径。硬质闪光照亮人物背部和地面，远处深黑，一团冷白烟雾在人物旁升起。红棕地面、黑色服装与红光形成克制配色。35mm 胶片颗粒，真实抓拍。人物与犬只数量固定，不要多余动物、肢体融合、文字乱码或水印。
```

原文可替换项：人物、自有 Logo、犬种；没有 Logo 时删除文字要求，保持纯黑背部。主体图路径默认保留黑色天鹅绒夹克、宽松长裤、三只黑色杜宾犬、红色牵引线、冷白烟雾和红棕地面。不凭空添加品牌或文字。

**MV 动态补充**

- 音乐：默认 96 BPM、4/4 暗黑 Hip-hop，干硬鼓点、深低频与少量工业纹理；原创短句说唱，脚步与收紧握持对应拍点。
- 表演：主体背对镜头前行、侧身回望演唱、稳住牵引线后停步；三只犬保持独立轮廓并向画面左侧运动。人物行走与犬运动衔接，不让犬将人物拖离画面。
- 摄影与剪辑：背部中景建立母题，侧跟人物和犬群，低机位拍爪步与牵引线，再切可辨认身份的侧脸或正面演唱。红线穿过烟雾形成视觉路径，硬质闪光只在关键节拍使用。
- 30 秒推进：0–3 秒红线、爪步与冷白烟雾钩子；3–11 秒背部跟拍建立位置；11–19 秒侧身演唱与握持细节；19–27 秒侧跟犬群和人物前行动作高潮；27–30 秒人物停稳、完成末句与落版，犬仍有受控小幅运动。
- 连续性：默认恰好三只黑色杜宾犬；每条红色牵引线的握持端和项圈端明确，不穿过肢体、不合并成多余肢体。无自有 Logo 时全片夹克背部纯黑；不加入汽车、烟火、悬浮或现场乐队。
