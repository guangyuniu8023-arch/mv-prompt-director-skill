# Prompt Templates

在编写完整提示词前读取。生成视频模式由 Agent 完成提示词，再通过当前可用的视频生成工具提交；仅提示词模式直接交付代码块。图片标记用于说明参考分工，提交时按实际工具要求关联素材，不能只写标记而不传入素材引用。方括号为编写提示，正式交付必须全部替换或省略不适用部分。未指定画幅时统一使用 16:9 横幅，开头目标、分镜构图与实际请求规格保持一致。只使用当前模式所需模板，不让用户填写内部分析表。

## 完整 30 秒 MV

```text
【目标与参考分工】
创作[时长，默认 30 秒]、[画幅，默认 16:9 横幅]音乐 MV，面向[用户指定模型，默认 Seedance 2.5]。
当前路径：[有风格参考图时写“参考图驱动”；只有主体图时写最终采用的一套风格，不列出其余候选]。
@图片1：[主体图/风格参考图；辨识内容；负责的身份/穿搭/场景/灯光/色彩/氛围；必须保留与允许变化的范围]。
@图片2：[同上，按实际图片数继续]。
人物与场景关系：[现实、梦境、平行或连续；身份是否独立]。
[多人主体时分别写角色、图内辨识位置、原服装锁定项、场景位置和演唱分工；单人时省略多人条目]。
风格参考图中出现的其他人物只提供造型或画面风格，不替换主体身份。[没有风格参考图时省略]。
参考图支持场景内的新机位、景别和动作，不强制每图仅对应一个固定镜头。

【叙事与视觉】
[一句微叙事或情绪推进；开场、转折、高潮、落版及用户指定时点]。
[共同色彩、光线、材质；各场景允许的差异与连接方式]。
[环境/人物关系、主动表演、细节和运动高潮的拍摄分工]。
[确有运镜标记时排除其出现在成片，实物线绳保留]。

【音乐、歌词与声音】
[用户指定的音乐风格与语言优先；BPM/拍号、主要音色、主唱身份、各段声部变化；多人接唱、合唱或共享主唱的分配]。
[关键切点/动作与鼓点、停顿、drop、人声的对应关系]。
歌词：[逐句列起止时间、角色、原创新歌词、可见演唱或画外音；无歌词时明确]。
[动作声源、空间声学、人声与音乐/声效让位关系]。
全片声音连续，歌词跨镜头继续，不重启整首歌。

【逐镜编排】
镜头01｜[开始—结束秒]｜[任务、景别、机位/镜头特征]
[对象与开场构图]。
[摄影机起点→路径/速度/焦点→结束构图；固定机位则说明动作如何展开]。
[人物主动动作的起势、落点与余势；环境/道具次级运动]。
[本镜覆盖的歌词或拍点、同步声]。
[剪切触发、出口与下一镜入口关系]。

[按实际时长与镜头数继续，不能留省略号]。
[开场闪切可成组列出内部运动片段及时间，明确与主要镜头数的关系]。

【连续性与落版】
[主体身份来源；风格图人物不迁移身份；各角色的服装、数量、持握者与占用手、物理连接；特殊状态与允许活动的对象]。
[返回场景时延续动作，跨场景不融合]。
[最终构图、可读时长、完成动作与环境余韵，和镜头表一致]。
[只针对当前素材的关键失败约束]。

【输出】
[一个明确的时长与画幅，未指定画幅时为 16:9 横幅；镜头总数或主要镜头与内部闪切的明确计数；按需写帧率]。
[全片音乐、演唱与动作声一起输出；其他用户明确要求]。
```

## 单场景

```text
【参考与目标】
@图片1：[主体、身份、服装、道具与场景锁定]。
[指定时长、画幅（未指定时为 16:9 横幅）、连续镜头或允许剪切、视觉气质]。

【摄影与表演】
[起始机位/景别→路径与速度→焦点/构图变化→结束构图]。
[明确行动或演唱、动作起势与余势；道具和环境独立运动]。
[光源、前景、透视如何随拍摄位置改变]。
[固定机位则说明画面内部发展；有箭头则说明仅作引导]。

【音乐与声音】
[风格、节奏、人声、歌词长度与分配、动作声与同步位置]。

【连续性与结束】
[实际存在的身份/数量/连接/标识/特殊状态风险]。
[结尾停留时间与继续发生的动作，符合用户要求]。
```

## 修订交付

简短说明改了什么、依据是用户反馈还是实际观看。按上述模式完成完整提示词，不能只给补丁段落。仅提示词修订交付代码块；用户要求重新生成时用完整修订版提交新任务，随后交付视频。

服装、歌词、音乐或画幅的局部修改沿用已选预设；明确指定换套时直接切换，明确要求重新随机时才重抽。

内部核对：受影响模块 → 已确认保留项 → 时间/歌词/转场依赖 → 完整修订 → 下一次生成观察的 2–3 个现象。
